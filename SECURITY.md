# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release of Neon Song.

| Version | Supported          |
| ------- | ------------------ |
| 4.2.x   | Yes                |
| < 4.2.5 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Neon Song, please report it privately rather than creating a public issue.

### How to Report
* Submit a private security advisory or open an issue through the GitHub repository:
  * https://github.com/ansh2222949/Neon-song/security/advisories
* Include:
  * Description of the vulnerability
  * Affected versions and components
  * Steps to reproduce or proof-of-concept
  * Potential impact assessment

### Response Timeline
* **Initial acknowledgment:** Within 48 hours.
* **Assessment & mitigation plan:** Within 5 business days.
* **Public disclosure:** Coordinated after a patched release is published.

Thank you for helping keep Neon Song secure for all users.
